# 📌 Projetos em Destaque

### 🧠 Kavumi | Plataforma Educacional Full Stack

![Status](https://img.shields.io/badge/Status-MVP_em_Validação-F59E0B?style=flat-square)
![Full Stack](https://img.shields.io/badge/Full_Stack-TypeScript-3B82F6?style=flat-square)

O **Kavumi** é uma plataforma educacional interativa desenvolvida para apoiar a aprendizagem de estudantes do Ensino Fundamental, proporcionando uma experiência de estudo dinâmica, acessível e envolvente.

Projeto autoral desenvolvido de ponta a ponta, desde a concepção da ideia até a implementação e disponibilização do MVP.

**🚀 Destaques técnicos:**

- Desenvolvimento de aplicação Full Stack com TypeScript.
- Construção de API REST com Node.js e Fastify.
- Modelagem e persistência de dados com PostgreSQL e Prisma ORM.
- Implementação de autenticação e autorização com JWT.
- Integração entre frontend e backend.
- Desenvolvimento de MVP com foco em experiência do usuário e validação do produto.

**🛠️ Tecnologias:**

`React` · `TypeScript` · `Node.js` · `Fastify` · `Prisma` · `PostgreSQL` · `JWT`

**📌 Status:** MVP publicado e em fase de validação.
